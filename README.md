# GeoChat Agent HQ page

The web page for GeoChat Agent HQ. Built from `page/` in the private `venuswong/geochat-hq` repo; edit it there, not here.

It holds no secrets. `config.js` has the project URL and the public anon key, which only let a browser reach the database's API, where row-level security decides what each login may see or do. Only Venus's own login can answer agents' questions.
